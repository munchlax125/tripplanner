# 여행 일정·예산 — 수정 방법

**`src/` 안의 YAML만 고치고 빌드하면 됩니다.** HTML·엑셀을 직접 건드리지 마세요 (덮어써집니다).

```bash
python build.py        # src/일정.yaml  →  조지아_아르메니아_최종일정_상하이반영.html
python build_xlsx.py   # src/예산.yaml  →  여행예산_상하이반영.xlsx
```

---

## 파일 구조

```
src/
  일정.yaml          ← 일정 본문 (여기를 고칩니다)
  예산.yaml          ← 교통·입장료·일자별 예산 (여기를 고칩니다)
  head.html          ← <head> + CSS (디자인)
  script.html        ← 온라인 지도 버튼 스크립트
  예산_템플릿.xlsx     ← 서식·수식 원본
  basemaps/
    m00.svg … m16.svg  ← 오프라인 지도 바탕그림
    _proj.json         ← 지도별 위경도→픽셀 변환식

build.py             ← HTML 생성기
build_xlsx.py        ← 엑셀 생성기
_backup_일정.html     ← 생성기 도입 전 원본
_backup_예산.xlsx     ← 〃
```

## 자주 하는 수정

### 시각·내용 바꾸기
`src/일정.yaml`의 `blocks` → 해당 날짜 → `sched` → `rows`

```yaml
- t: '14:00'
  bus: 마르슈르트카          # 파란 알약 뱃지 (없으면 생략)
  text: 예레반행 607번
  tag: {text: 무료, hot: false}   # 회색 태그 / hot:true면 빨강
  small:                     # 회색 보조설명 (여러 줄 가능)
    - 3,000드람 · 4~5시간
```

### 지도 지점 바꾸기
`src/일정.yaml`의 `map_points` → 지도 id → `[이름, 위도, 경도]` 목록만 고치면
**투영·축척·마커·라벨·경로선·순서 문구·구글지도 링크·온라인 지도 데이터가 전부 자동으로 다시 만들어집니다.**

```yaml
m05:
  - [스테판츠민다, 42.6583174, 44.6409521]
  - [주타 · 차우키, 42.5556, 44.7486]
  - [트빌리시, 41.6899414, 44.8035657]
```

- 지점이 바탕그림 밖으로 나가면 **자동으로 축소·이동**해서 맞춥니다 (축척 막대도 같이 조정).
- 같은 곳을 두 번 들르면 마커 하나에 `1·4`처럼 번호를 묶어 표시합니다.
- 라벨은 좌우·상하 충돌을 피해 자동 배치됩니다.

> ⚠️ 바탕그림(해안선·도로)은 원본 자산이라 **새로운 지역은 그릴 수 없습니다.**
> 기존 17장이 덮는 범위 밖으로 가려면 가까운 바탕그림을 재사용하거나 `[실제 지도 불러오기]` 버튼에 맡기세요.

### 예산 항목 추가·삭제
`src/예산.yaml`의 `transport` / `tickets`에 행을 넣거나 빼면 됩니다.
**합계 수식과 SUMIFS 참조 범위는 행 수에 맞춰 자동으로 다시 씁니다** — 손으로 맞출 필요 없습니다.

```yaml
- date: 9/25
  seg: 트빌리시 → 시그나기 왕복
  mode: 마르슈르트카
  kind: 시외          # 시외 / 시내  (일자별예산 집계 기준)
  amt: 25
  cur: GEL           # GEL AMD EUR AED CNY
  pub: '○'           # ○ 대중교통 / △ 부분 / ✕ 택시 필수
  note: 삼고리 터미널 출발 · 편도 2~2.5시간
```

`날짜` 문자열이 `일자별예산`의 날짜와 정확히 같아야 집계됩니다 (`9/25`, `10/1` 형식).

## 검증

수정 후 아래로 확인하세요.

```bash
python build.py
python -c "import re;s=open('조지아_아르메니아_최종일정_상하이반영.html',encoding='utf-8').read();
print([(t,len(re.findall('<%s[ >]'%t,s)),len(re.findall('</%s>'%t,s))) for t in ('div','ul','li','svg','p','span')])"
```

열린 태그 수와 닫힌 태그 수가 같으면 정상입니다.

엑셀은 **열어두면 저장이 막힙니다.** 빌드 전에 Excel을 닫으세요
(닫혀 있지 않으면 `_new_예산.xlsx`로 대신 저장됩니다).

## 알려진 제약

| 항목 | 내용 |
|---|---|
| 바탕그림 | 새 지역은 생성 불가 (원본 자산 재사용만 가능) |
| 엑셀 캐시값 | openpyxl이 계산값을 비우므로 Excel에서 열면 자동 재계산됩니다 |
| 숙박비 | `예산.yaml`의 `days[].stay`에 원화 정액으로 들어갑니다 (환율 연동 아님) |
