# backup — 스바네티 루트로 바꾸기 직전 상태

2026-09-08 에 지상 구간을 **스바네티 루트**로 다시 짜면서, 그 직전의 조지아·아르메니아 일정을
통째로 여기에 남겨 두었습니다. 항공 3편·날짜·경유지는 두 판이 같습니다 — **다른 것은 지상 구간뿐**입니다.

## 들어 있는 것

```
backup/
├── src/
│   ├── 일정.yaml            ← 예전 지상 루트
│   ├── 예산.yaml            ← 예전 예산 (rate_sheet 포함)
│   └── basemaps/
│       ├── m00.svg          ← 예전 개요 지도 (스바네티가 안 들어간 범위)
│       └── _proj.json       ← 예전 투영 정보 (m00~m24, m25~m27 없음)
└── 결과물/                   ← 위 소스로 다시 빌드한 산출물
    ├── 조지아_아르메니아_최종일정_상하이반영.html
    └── 여행예산_상하이반영.xlsx
```

`m01`~`m24` 는 두 판이 같은 파일을 쓰므로 여기 넣지 않았습니다. `src/basemaps/` 의 것을 그대로 씁니다.

## 되돌리는 법

```bash
cp backup/src/일정.yaml backup/src/예산.yaml src/
cp backup/src/basemaps/m00.svg backup/src/basemaps/_proj.json src/basemaps/
python build.py
python build_xlsx.py
```

`_proj.json` 을 되돌리면 **m25·m26·m27(메스티아·우쉬굴리·코룰디) 항목이 사라집니다.** 예전 판은 그 지도를
쓰지 않으니 그게 맞습니다. 나중에 다시 스바네티로 가려면 `git` 에서 새 `_proj.json` 을 꺼내거나
`tools/make_basemap.py` 로 세 장을 다시 만들면 됩니다.

되돌린 뒤에는 산출물을 열어 **일 16 · 국경 4 · 지도 16 · 노트 18** 이 나오는지 확인하세요.
새 판은 **일 16 · 국경 7 · 지도 15 · 노트 16** 입니다.

## 부분만 가져오고 싶다면

두 `일정.yaml` 은 같은 스키마라 블록 단위로 옮길 수 있습니다. 예를 들어 카헤티(시그나기·보드베)만
되살리고 싶으면 예전 파일의 `9.26` 블록과 `map_points.m14`, 그리고 `예산.yaml` 의 해당 `transport`·
`tickets`·`days` 행을 함께 가져오세요. **날짜 문자열이 세 곳에서 정확히 같아야 집계됩니다.**
